# 三國演義 (Romance of the Three Kingdoms)

## 簡介

《三國演義》是中國四大古典名著之一,由元末明初的小說家**羅貫中**所著,是中國第一部長篇章回體歷史演義小說。全書以東漢末年到西晉初年的歷史為背景,描寫魏、蜀、吳三國之間的政治與軍事鬥爭。

## 故事背景

東漢末年,朝政腐敗、宦官外戚專權,爆發黃巾之亂,群雄並起。此後天下逐漸分裂為三個政權:

| 國家 | 建立者 | 都城 | 代表人物 |
| ---- | ------ | ---- | -------- |
| 魏 | 曹丕(奠基者曹操) | 洛陽 | 曹操、司馬懿、張遼 |
| 蜀 | 劉備 | 成都 | 劉備、諸葛亮、關羽、張飛、趙雲 |
| 吳 | 孫權(奠基者孫堅、孫策) | 建業 | 孫權、周瑜、陸遜、呂蒙 |

## 著名情節

- **桃園三結義**:劉備、關羽、張飛在桃園結為異姓兄弟
- **三顧茅廬**:劉備三次拜訪諸葛亮,請其出山輔佐
- **赤壁之戰**:孫劉聯軍以火攻大敗曹操
- **草船借箭**:諸葛亮以智謀向曹軍「借」得十萬支箭
- **空城計**:諸葛亮以空城退司馬懿大軍
- **七擒孟獲**:諸葛亮南征,七次擒放孟獲使其心服

## 主題與特色

- 「**尊劉貶曹**」的正統觀念,塑造劉備仁德、諸葛亮智慧、關羽忠義的形象
- 全書開篇名句:「**話說天下大勢,分久必合,合久必分。**」
- 「七分實事,三分虛構」,結合正史《三國志》與民間傳說
- 對後世戲曲、評書、影視、遊戲等影響深遠

## 相關資源

- 正史:陳壽《三國志》
- 小說:羅貫中《三國演義》(現行通行本為毛宗崗評改本)
